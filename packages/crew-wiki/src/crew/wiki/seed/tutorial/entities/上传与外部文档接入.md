# 上传与外部文档接入

你可以把已有的外部文档接进 Wiki：产品文档、会议记录、规范文件，统一变成可检索的知识页面。资料完全由你主动接入，没有自动采集。

## 支持的方式

| 方式 | 说明 |
|---|---|
| 上传文件 | 支持 Markdown、TXT、PDF 等格式，通过 WikiHub 导航器里的上传按钮 |
| 粘贴文本 | 直接把一段文字粘贴进来，作为原始资料 |

## 背后的流程

```
你上传 backend-spec.pdf
  → 文件保存为原始资料（raw source），并解析成 Markdown
  → AI 读取原始资料，分析内容
  → 发布可检索的来源摘要页
  → 提取关键词、话题、主张、证据和页面关系
  → 返回生成的页面卡片
```

两个关键点：

- **原始资料不可变**：上传的内容原样保存，AI 只读不改，之后可以基于它重新编译。
- **一份资料可能生成多个页面**：AI 会按内容拆出不同主题和概念，并互相链接 —— 这正是知识库的复利效应，见 [[LLM Wiki 与 RAG 的区别]]。

## 上传后的反馈

上传完成后不需要自己找页面在哪：

1. 上传任务显示保存、解析、分析和整理阶段。
2. 来源摘要发布后即可被检索。
3. 深度整理继续创建或更新关键词、话题和关系。

时间视图的日期分组规则见 [[页面类型与浏览视图]]。

## 之后怎么用

文档变成页面后，就可以像查任何 Wiki 一样用对话检索："部署流程里灰度发布怎么做？" AI 会先查这些页面再回答，见 [[用对话操作 Wiki]]。
