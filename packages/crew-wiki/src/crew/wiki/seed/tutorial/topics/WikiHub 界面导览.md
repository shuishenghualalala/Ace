# WikiHub 界面导览

WikiHub 是浏览、编辑和查询知识库的主界面。进入方式是点击左侧导航栏的 **Wiki**。

## 三栏布局

进入 Wiki 后是三栏工作区：

| 区域 | 内容 |
|---|---|
| 左侧 | 页面导航：时间线、文件树、类型或图谱 |
| 中间 | 当前文档详情，可直接修改标题和正文 |
| 右侧 | 当前知识库专属 Wiki Agent 对话 |

## 中栏：导航器

顶部视图包括 **时间线 / 文件树 / 类型 / 图谱**。时间线按今天、昨天、本周、本月和更早分组；文件树按实际目录浏览；类型视图按来源摘要、关键词、话题等分类。详细说明见 [[页面类型与浏览视图]]，关系网络见 [[知识图谱视图]]。

点击页面后，中间详情栏展示标题、类型、时间、来源、正文和相关页面。标题与正文可以直接修改并自动保存；来源和关系可点击跳转。

## 知识库管理

顶部可以切换、新建和删除知识库。右侧 Wiki Agent 始终绑定当前选中的知识库。内置的“我的工作”和“LLM Wiki 使用教程”不可删除，但教程页面仍可修改。

## 上传按钮

点击“上传”会打开右侧 Wiki Agent 的附件选择；也可以把文件拖入或粘贴到输入区。支持的文档、图片和视频类型由上传控件提示。解析和整理进度会在界面中持续更新，流程见 [[上传与外部文档接入]]。

## 浏览不打断对话

页面详情和 Wiki Agent 分栏并列。浏览或编辑页面时，对话记录、草稿和附件不会被清空。

页面和内容的删除、修改等管理手段见 [[隐私控制与内容管理]]。
