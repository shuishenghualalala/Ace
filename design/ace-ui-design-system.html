01 / Foundations

原则与主题

统一的是视觉语言、交互状态和工程边界，不是把所有功能强行塞进同一种卡片。

安静的工作台

内容、状态、比较和重复操作优先。避免营销式构图和装饰性视觉。

边框先于阴影

稳定结构使用 1px 边框。只有离开文档流的浮层才使用阴影。

动效解释变化

只为反馈、状态转换和空间连续性服务，不使用弹跳、发光和无意义循环。

例外保持局部

Studio 保留深色场景画布与黄/奶油色像素操作层；皮肤只能作用于自身根节点，不切换全局主题。

主题契约

支持：system / light / dark / high-contrast

移除 sepia、sidebar-gray 和自选强调色。Light 的 app/canvas/surface 为纯白，Dark 的 app/canvas 为纯黑。

图形迁移边界本页内联图形用于规范阶段确认，不是第二套生产 Sprite。新 Renderer 的首个迁移切片必须把已批准的 Wiki 与过程图标收敛进生产唯一 Sprite，并让生产 Preview 与本页共同引用该资产。

13 / Acceptance

可访问性与工程验收

目标 WCAG 2.1 AA。可访问性、内容一致性与静态门禁都属于完成条件，不是后续优化。

  • 普通文字对比度至少 4.5:1，UI 边界至少 3:1。
  • 所有命令优先使用原生交互元素，键盘顺序与视觉顺序一致。
  • 焦点始终可见；图标按钮有可访问名称和 Tooltip。
  • 颜色不是唯一状态信号；重要状态同时使用文字或图标。
  • Modal 管理并恢复焦点，Escape 关闭可取消浮层。
  • 支持 reduced motion、高对比主题和 200% 文本缩放。
  • 原始颜色只存在于 tokens.css primitive；主题、组件、页面、图表和 SVG 消费者中出现原始颜色直接失败。
  • 跨文件冲突选择器、未定义/死 Token、旧 CSS owner 和非白名单 !important 直接失败。
  • 1440×1000、1280×800、960×640 均无 body 横向溢出。
  • Context、Files、Plan、Kanban、Team、Browser 六类 Inspector 都有适用状态和键盘行为。
  • 迁移清单中的现有页面、设置 Pane、登录、更新与反馈在删除 legacy 代码前均完成行为核对。
  • 新增页面选用既有模板并覆盖完整数据状态矩阵。
  • 通用助手逐页和弹窗布局与 master 对齐；非聊天页没有历史占位；历史折叠后完全移除该列，展开历史与折叠态新建对话入口位于“对话 / 工作室”旁且不进入主导航。
  • 历史列表保持项目/普通对话分组和单行紧凑结构；首发只保留中性占位，首条用户输入不得成为标题，生成摘要到达后完整写入标题节点与悬停提示，视觉层可省略；列表自身拥有纵向滚动，指针位于任意会话行时均支持滚轮与触控板；行尾显示时间或运行状态，悬停/键盘聚焦平滑显现操作按钮，并支持 reduced motion。
  • 历史折叠/恢复使用面板语义图标，折叠态新建会话使用对话加号图标；项目悬停背景覆盖包含尾部操作按钮的整行。
  • Markdown 围栏代码、工具 Request/Response 内容和安全审批摘要无需选中即可阅读，前景/背景使用配套语义 Token 且对比度至少 4.5:1；完全访问使用产品主题确认弹窗并在用户确认后才提交模式。
  • Inspector 数字使用固定居中盒；Skills/Plugins 与 Expert/Team 卡片按内容收紧高度，隐藏动作不占内容列，普通标签中性化且保留键盘可达的悬停动作。
  • Skill 卡片采用名称、说明、元数据三行轨道，说明长短不改变底部分类标签基线；主按钮的单色图标必须使用按钮文字色。
  • Usage 设置页只出现一组标题与说明；Audit/Security/System 成功刷新保持安静，仅加载、部分可用、离线与失败状态显示状态提示。
  • 系统日志筛选使用标准字段、开关和图标按钮；普通更新弹窗可关闭或取消。强制更新只响应服务端强制策略，并在全部执行中会话结束后才显示不可取消阻断层。
  • 历史栏使用连续 Surface 背景，工作空间作为“项目”的缩进子级；推荐场景展开命令时品牌、标题与三张场景卡保持原位。
  • Skills/Plugins 与 Expert/Team 详情使用共享中性遮罩、焦点循环和恢复，并按介绍、元数据、成员/工具及操作区建立明确层级。
  • 专家/技能说明小于名称并使用次级前景；技能卡保留舒适高度，“推荐”和“新”不作为装饰 Badge 重复展示。
  • Wiki 工具栏控件尺寸稳定且标签不换行，导航、拖拽条、详情和 Agent 显式占据轨道，隐藏拖拽条不得吞掉详情；Audit 与反馈记录复用支持每页数量、首页/尾页、页码和数字跳转的服务端分页，分页按组换行；Security 操作画布占满可用宽度，仅说明文本限制阅读宽度。
  • 反馈记录的“查看”使用标准小型次要按钮；详情使用共享 Modal，标题、状态、编号、提交时间、正文、附件和回复形成稳定层级。
  • 渠道列表只保留图标、名称、连接状态和直接动作；MCP 长错误在卡片内换行；模型卡片有宽度上限且短状态使用内容宽度 Badge。
  • Skills/Plugins、Expert、Audit、Security、Welcome 和 Work 全部入口通过真实交互与三视口验收。
