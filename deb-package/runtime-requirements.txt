# Crew 安装包内嵌 Python 的依赖清单（三平台唯一数据源）。

#
# 打包态下 gateway 与技能脚本共用同一个内嵌解释器，因此依赖分两部分：
#   1. gateway 核心依赖 + wiki/pdf/docx/xlsx 技能依赖
#      → 由 pyproject.toml 维护，各脚本执行：
#          pip install ".[wiki,pdf,docx,xlsx]" && pip uninstall -y crew

#   2. 本文件：pyproject 未覆盖的技能脚本补充依赖
#
# markitdown 固定 0.0.2 并由各脚本以 --no-deps 单独安装：
# 0.1.x 顶层 import magika（拖入 onnxruntime，超 100MB），0.0.2 无此问题。
# 下面 mammoth/olefile/puremagic/azure-* 是 markitdown 0.0.2 的顶层 import 硬依赖

# 注意 pydub / SpeechRecognition 是 markitdown 的惰性依赖（仅音频转写路径用），
