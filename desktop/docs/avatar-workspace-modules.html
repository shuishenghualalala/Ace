Ace Desktop 头像与工作空间模块

更新日期：2026-08-28 · 范围：Desktop UI 与 Desktop 类型层

本次更新

  • 新增 src/ui/avatar-manager.ts，统一头像身份、来源校验、DOM/HTML 渲染和 fallback。
  • Crew、同伴、外援、Team 看板、会话历史和聊天消息改为通过公共头像模块读取。

头像归属边界

身份数据归属公共模块行为
Crew内置身份统一使用 Crew 默认头像
同伴用户Nearby/Companion优先用户头像，缺失时按用户名称 fallback
同伴 AgentNearby/Companion优先发布 Agent 头像，缺失时按 Agent 名称 fallback
外援 Agent/TeamExternal继续使用既有外援头像样式和 provider/Team 标识；头像归属仍由 External 模块负责
Wiki/系统身份各自模块使用模块指定图标

工作空间模块边界

WorkspaceRegistry 只管理模块注册、导航入口和生命周期，不持有任何业务数据。每个域继续拥有自己的 API、状态和页面实现，后续可以通过注册新模块增加 Desktop 功能。

模块 ID类型负责内容
conversation普通对话默认对话和通用会话
companion同伴发现、私聊、群聊和同伴 Agent
external外援外援 Agent、Team 和外援会话
wikiWikiWiki 工作区和 Wiki Agent
project项目用户本地目录和办公工作空间

数据协议说明

当前 Nearby native 协议的 PeerInfo 和 PublishedAgent 尚未携带头像字段。本次 Desktop 改动已支持可选字段并安全忽略非法来源；要显示其他设备的真实头像，后续仍需在 Desktop 随附的 Nearby 通道中补充头像字段。
