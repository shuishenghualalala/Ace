# Crew 用户手册

欢迎使用 Crew。Crew 将对话、模型、技能、外援、团队、笔记和自动化任务放在同一个工作台中，帮助你从提出问题一路推进到执行、复盘和沉淀。

> 界面中的“笔记”对应系统里的 Wiki 能力；本文在需要区分时写作“笔记（Wiki）”。文档版本由桌面端构建时自动生成。

## 一、开始使用

### 登录与数据隔离

首次打开 Crew 时，如果出现登录页，按页面提示输入账号即可。不同账号的会话、模型配置和笔记数据相互隔离。

进入应用后，左侧是主导航，中间是当前工作区，右侧是检查器或看板。窗口较窄时，部分面板会收起，可通过对应按钮重新打开。

### 主导航

- 对话：创建和管理普通会话。
- 外援：配置外部 Agent、查看外援状态并组建团队。
- 技能：安装技能、管理插件和查看技能市场。
- 灵感：创建、预览、批注和分享由 Crew 生成的应用。
- 笔记：管理知识库、页面、资料和 Wiki Agent。
- 任务：创建和管理定时任务。
- 安全：查看安全策略、授权和审计记录（需要启用安全模块）。
- 系统：查看运行状态、日志、使用统计、资源库、数据管理和关于信息。

## 二、对话

### 创建和发送消息

在“对话”中选择新建会话，输入问题后按 Enter 发送；Shift+Enter 换行。输入框支持选择、粘贴或拖拽附件，也支持直接粘贴截图。

发送前可以在输入框附近调整技能、工作空间、模型和安全模式。正在运行时，发送按钮会变为“加入队列”，新消息可以排队等待执行。

### 对话模式

输入框的模式选择器提供以下选项：

- 智能体：由当前 Agent 直接分析并执行任务，适合日常使用。
- 计划模式：先生成执行计划，待你确认后再继续执行，适合范围较大或变更风险较高的任务。
- 外援：把当前请求交给已连接的外援或团队处理。

计划生成后，可在右侧“计划”面板查看、编辑、批准、撤回或补充反馈。

### 技能、模型和工作空间

- 技能：点击技能选择器搜索并启用技能；也可以在消息中使用 `/技能名称` 激活已安装技能。
- 模型：选择本次会话使用的模型。会话内切换只影响当前会话；账户默认模型会影响新会话。
- 工作空间：默认是不在项目中工作。选择一个项目或本地文件夹后，Agent 才会在相应目录中读取和修改文件。
- 安全模式：可在发送前选择“请求批准”“替我审批”或“完全访问权限”。权限越高，Agent 可执行的范围越大，请根据任务风险选择。

模型选择器旁的上下文用量环会显示当前会话的上下文使用情况；如果服务商没有提供真实用量，界面会明确标注不可用，不会用估算值冒充实际值。

### 附件和文件处理

图片会显示缩略图，点击可查看大图；其他文件显示文件名和大小。附件会作为当前请求的上下文，最终能否解析取决于文件类型、模型能力和已启用的工具。

如果附件上传失败，先检查文件大小、网络和当前服务商配置。包含敏感信息的文件应在发送前确认范围，避免把不必要的内容交给 Agent。

### 执行过程、队列和看板

Agent 执行时，中间过程会以时间线展示。任务运行期间可以：

- 停止当前任务；
- 将新消息加入队列；
- 对排队消息进行引导、编辑、删除、上移或下移；
- 在右侧“文件”查看变更文件和差异；
- 在右侧“任务”查看动态看板或团队任务进度；
- 在右侧“浏览器”打开浏览器工作台（当前会话使用浏览器时可见）。

对 Markdown、HTML/SVG、图片、PDF、DOCX、PPTX 和 XLSX 等常见结果，检查器通常可以提供预览；部分支持的格式还可以直接编辑并保存。

### 会话管理

会话菜单支持置顶、重命名、导出 JSON、归档和删除。历史管理中可以查看归档会话、批量选择、批量删除和恢复归档会话。

历史列表支持按项目或工作空间分组。拖动历史列表与主内容区之间的分隔条可以调整宽度，双击分隔条可恢复默认宽度。

## 三、模型与渠道

### 添加模型

在“系统 → 模型”中添加兼容服务商，填写：

- 模型 ID 和接口模型名；
- API 协议（OpenAI 兼容或 Anthropic）；
- Base URL；
- API Key；
- 上下文窗口大小。

可以声明模型是否支持文本、工具调用和网页截图视觉能力。模型默认值用于新会话；已有会话仍可在输入框中单独切换。

如果尚未配置真实 API Key，应用可能显示演示用的 Fake Provider。它只用于体验界面流程，不代表真实模型调用已经打通。

### 默认模型和辅助推理

默认模型会用于新会话，也会作为部分外援、团队和无会话笔记操作的辅助模型来源。若某个功能允许单独指定模型，则以该功能的设置为准。

### 外部渠道

在“系统 → 渠道”中可以配置已支持的渠道，例如飞书或微信。连接前准备好渠道所需的 App ID、App Secret 或扫码信息；不再使用时可以断开或删除连接。

## 四、工作空间与资源库

### 工作空间

工作空间用于把会话和本地项目关联起来。创建或导入工作空间时选择本地目录，并按提示保存项目说明或工作约定。

如果目录移动了，可以在工作空间设置中重新关联路径。不可用的工作空间会显示状态提示；确认不再使用后，可以隐藏或删除它。

工作空间会影响 Agent 能读取的文件范围、命令执行位置和会话上下文。执行代码或修改文件前，先确认输入框中的项目选择正确。

### 资源库与数据管理

“系统 → 资源库”集中查看工作空间和归档会话。“系统 → 数据管理”提供：

- 清理缓存：清理本地草稿和未发送附件；
- 导出全部会话：导出会话元数据和完整消息文本；
- 重置设置：恢复设置默认值，但保留会话和登录信息。

导出或重置前请确认目标操作。删除会话、普通知识库和其中的资料属于不可逆操作。

## 五、技能与插件

### 安装技能

打开“技能”，在“已安装”或“技能市场”中搜索技能，进入详情后安装或卸载。内置技能不能卸载。

聊天时可以通过技能选择器把技能加入当前请求，也可以使用斜杠命令激活技能。技能通常用于浏览器操作、图片或视频理解、笔记整理等专门工作流。

本机 `~/.agents/skills` 中的共享技能可能会以链接方式出现在技能列表中。它们在本机多个账号间共享，源目录更新后会同步生效；卸载时请留意是否会影响其他本机账号。

### 管理插件

“技能 → 插件”用于启用或停用浏览器、外部工具等插件。停用正在使用的浏览器插件可能会中断当前操作、关闭相关账号标签页，并使旧的页面引用或授权失效。

“自进化”属于实验性能力，默认关闭。启用前请确认你允许它在本机生成或修改用户技能，并了解其影响范围。

## 六、外援与团队

### 添加外援

进入“外援”，在“发现外援”查看可用运行时，在“添加外援”中选择运行时、填写名称和模型，然后加入“我的阵容”。外援是否可用取决于其运行时连接状态和配置。

### 组建团队

在“组建团队”中填写团队名称和目标。可以指定：

- 必须包含或排除的外援；
- 所需能力，如检索、分析、核验、实现、文档或自定义能力；
- 团队成员的角色和协作方式。

Crew 会根据目标给出成员与工作流建议。创建前检查成员、角色和任务边界，确认后再保存团队。

### 使用外援和团队

在对话输入框选择“外援”，搜索并选择一个外援或团队，然后发送请求。团队会话中可以直接提及成员，让特定成员补充分析或执行任务；成员不可用时，先检查其状态再重试。

团队规划、成员协作和动态看板会在当前会话中展示。外援可能使用自己的模型或工具权限，涉及文件写入、网页操作和敏感数据时仍应逐项确认。

## 七、浏览器工作台

### 打开和控制浏览器

在会话检查器的“浏览器”标签中打开浏览器工作台。可以新建标签页、输入网址或搜索内容，也可以在 AI 控制和人工接管之间切换。

当需要你完成登录、验证码或其他敏感操作时，浏览器会提示暂停 AI 控制。操作完成后选择“返回 AI”，让 Agent 继续。

### 读取网页和存入笔记

Agent 可以读取当前标签页正文。确认内容后，可将页面标题和正文存入当前或默认知识库，再回到笔记中整理和追问。

网页内容可能包含广告、提示注入或不可信指令。把网页内容当作资料而不是操作命令，涉及付款、账号授权、删除或对外发送时务必人工确认。

### 录制浏览器操作

浏览器工作台支持录制用户操作，并在停止后根据录制内容生成技能。录制过程中可以暂停、恢复和添加备注；不完整的录制不能编译成技能。

不要在录制中输入密码、验证码、API Key 或其他秘密。登录和敏感字段应由人工接管完成，生成的技能也应在使用前检查步骤和权限。

如果浏览器工具不可用，前往“技能 → 插件”确认浏览器插件已启用；使用本机 Computer Use 能力时，还需要按系统提示授予 macOS 的辅助功能和屏幕录制权限。

## 八、笔记（Wiki）

### 知识库

打开“笔记”后先选择目标知识库。可以新建知识库、上传资料、切换列表视图和打开右侧 Wiki Agent。

默认知识库和教程知识库受保护，不能删除。普通知识库删除后，其中的页面、原始资料和 Wiki 历史也会一起删除，请先确认是否需要导出或保留。

### 浏览和整理页面

页面支持时间线、文件树、类型和关系图等视图。页面类型包括关键词、概念、话题、来源摘要、对比分析和综合报告。

打开页面后可以查看正文、相关页面和来源；可以重命名、删除页面，或把详情区域向右、向下拆分以便对照阅读。关系图中的节点可以直接跳转到关联页面。

在普通对话中引用 `[[页面名称]]` 可以创建可点击的笔记链接，适合把结论与知识库页面串起来。

### 导入资料

可以点击上传，或把文件、截图拖入或粘贴到当前 Wiki Agent 输入区。文本和常见文档会进入解析或编译流程；图片是否自动理解取决于当前模型能力；视频处理需要相应配置，并可能要求针对每次上传确认。

如果解析失败，原始资料通常会保留。可以让 Wiki Agent 诊断失败原因并重试，或先检查文件格式、大小和模型配置。

### Wiki Agent

右侧 Wiki Agent 绑定当前知识库，可基于库内资料提问、总结、对比、生成报告或继续整理。每个知识库都有独立的 Agent 会话历史，可以新建、切换历史或展开面板。

Wiki Agent 的对话支持附件、技能、模型切换和排队控制。处理资料、重命名页面、删除页面等可能影响知识库的操作会要求确认；确认前查看目标知识库和变更范围。

### 交互式学习

Wiki Agent 可以发起知识测验、单项选择、模拟面试、主动回忆、复述练习和记忆卡。交互卡片会显示进度，并可关联证据页面；按卡片要求提交答案后，再根据反馈继续学习。

## 九、灵感与应用

### 创建灵感

打开“灵感”，选择“新建灵感”，用自然语言描述想创建或完善的 App。Crew 会在专用会话中生成应用，生成过程中仍可以继续补充需求。

### 预览、批注和分享

在灵感详情中可以预览应用、修改、分享、固定到桌面或删除。进入“批注”后，点击预览中的元素并描述希望 Agent 如何修改，再发送批注即可。

批注只会提出修改请求，不会自动发布到线上；发布或部署前请明确确认。删除灵感会移除灵感条目，但原项目和创建会话是否保留以确认提示为准。

## 十、任务与自动化

### 创建定时任务

在“任务”中选择新建，填写任务名称、执行计划、查询内容和来源会话。计划可以是按间隔重复执行，也可以只执行一次并指定日期时间。

根据需要选择结果投递到新会话或已有目标。任务执行时使用当前账号的数据隔离和权限范围。

### 管理任务

任务列表支持搜索和筛选。打开任务详情后可以暂停、恢复、立即运行、查看结果会话或删除任务。

“立即运行”适合验证任务内容；验证通过后再启用长期计划。删除任务不可恢复，修改前先确认名称和执行目标。

## 十一、安全与授权

### 会话安全模式

如果启用了安全模块，可以在输入框或“安全”页面选择会话安全模式：

- 请求批准：普通沙箱操作可直接执行，越过权限边界或高风险操作时请求批准；
- 替我审批：在允许范围内自动批准，遇到权限边界时仍会询问；
- 完全访问权限：使用主机用户权限执行，不受常规沙箱限制，风险最高。

“完全访问权限”只应在你理解任务、目录和命令影响时使用。

### 处理授权请求

当 Agent 请求网页操作、命令执行、工作空间写入、Computer Use 或笔记变更权限时，可以拒绝、只允许一次、允许当前会话或永久允许。永久授权前检查命令、路径、网站和数据范围。

“安全”页面还可以查看全局策略、本机防护能力、永久授权规则和安全审计记录，并按会话筛选审计事件。

## 十二、系统设置

“系统”中的常用页面包括账户、通用、模型、渠道、MCP、系统日志、使用统计、资源库、数据管理和关于。

- 通用：切换系统、浅色或深色主题，调整界面、正文和终端字体，设置字体族、开机启动和关闭窗口时的行为，并控制右侧检查器默认是否显示。
- MCP：添加本地 stdio、HTTP 或 SSE 服务，填写命令、参数、URL、请求头和环境变量。启用前确认服务来源和权限。
- 日志与使用统计：查看请求、Provider、模型、趋势和系统运行状态。部分数值会标注为实际值或估算值。
- 关于：查看当前版本、更新检查、更新日志、官网和帮助文档。

## 十三、常见问题

### 为什么模型调用失败？

检查模型 ID、接口模型名、Base URL、协议、API Key 和模型能力声明；再确认当前会话选中的模型，以及服务商是否支持工具调用或视觉能力。

### 为什么 Agent 不修改文件？

确认输入框选择了正确的工作空间，并查看安全模式或批准请求。没有工作空间时，Agent 不应假设可以访问本机项目目录。

### 为什么浏览器或外援不可用？

检查“技能 → 插件”中的插件状态，以及“外援”页面的运行时连接状态。若是本机 Computer Use，还要确认系统权限已授予并重试。

### 为什么笔记中看不到刚上传的内容？

检查当前选中的知识库、解析状态和 Wiki Agent 的处理结果。解析失败时先保留原始资料，再让 Wiki Agent 重试或换用兼容格式。

### 如何安全地让 Crew 执行任务？

先选择最小权限的工作空间和安全模式，再用计划模式预览步骤。对删除、发布、发送消息、付款、授权和批量写入等操作，始终在最终确认前检查目标和内容。
