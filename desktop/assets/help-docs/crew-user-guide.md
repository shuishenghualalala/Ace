# Crew 用户手册

Crew 是一个面向本地工作流的智能体工作台。你可以在同一个界面中组织对话、工作空间、技能、外援智能体、知识库和定时任务。

## 一、开始对话

1. 在侧栏进入“对话”，新建会话。
2. 在输入框中描述目标，并按需添加文件、选择工作空间或启用技能。
3. 发送后可在对话区查看回答、工具调用和任务进度。
4. 同一会话会保留上下文；主题明显变化时，建议新建会话。

### 对话模式

- **智能体模式**：直接分析并执行任务，适合大多数日常工作。
- **计划模式**：先生成可审阅的方案，确认后再执行，适合步骤较多或影响范围较大的任务。
- **外援智能体**：把任务交给已配置的外部运行时、外援或团队。是否可用取决于本机环境和管理员配置。

## 二、配置模型

未配置 API Key 时，Crew 会使用 FakeProvider 演示界面和消息链路，不会调用真实模型；首次对话会显示配置提示。要连接真实模型：

1. 打开“设置 → 模型”，点击“添加模型”。
2. 填写模型 ID、接口模型名、API 协议、Base URL 和 API Key。
3. 按模型实际能力选择文本、工具调用和视觉能力，保存后切换到该模型。

目前支持 OpenAI 兼容接口和 Anthropic Messages 接口。API Key 保存在当前用户的本地配置目录，不会显示在模型列表中；编辑模型时 Key 留空会保留原值。

## 三、工作空间

工作空间用于限定项目目录并保存项目级说明。

- 为不同项目创建独立工作空间，避免文件和上下文混用。
- 项目提示词会在该工作空间的新会话中自动生效。
- 让 Crew 修改文件前，请确认当前工作空间和目标路径正确。
- 输出到工作空间以外的位置时，Crew 会先请求确认。

## 四、技能

技能为智能体补充特定工作流和工具使用说明。

- 在“技能”页查看已安装技能和可安装技能。
- 可以在对话输入框中选择技能，也可以输入 `/技能名` 激活。
- 内置技能为本机共享能力；安装或卸载用户技能前，请确认影响范围。
- 安装第三方技能前，请检查来源、脚本行为、网络访问和所需权限。

## 五、外援智能体

“外援”页用于发现并管理本机可用的外部智能体运行时。

1. 在“发现外援”中扫描本机运行时。
2. 选择运行时和模型，把它加入“我的外援”。
3. 可以直接向单个外援派活，也可以把多位外援组成团队。
4. 外援会话和执行状态会按当前用户隔离；团队配置只引用当前用户可访问的外援。

如果没有发现可用运行时，请先确认对应工具已安装、可执行且允许 Crew 访问。

## 六、Wiki

Wiki 用于把项目资料整理成可检索、可浏览的知识库。

- 新建知识库后，可以导入文档或由 Wiki 智能体协助整理内容。
- 列表、关系和图谱等视图用于从不同角度浏览页面。
- 右侧 Wiki 智能体只在当前知识库上下文中工作。
- 导入前请确认资料不包含无权处理的敏感信息。

## 七、定时任务

定时任务支持单次提醒和周期执行。

- 可在“定时任务”页新建、暂停、恢复、立即执行或删除任务。
- 创建时确认触发时间、时区、执行内容和结果投递位置。
- 定时任务沿用创建时的 owner 上下文执行，不会读取其他 owner 的会话或任务。
- 修改或移除任务前，请核对任务名称和关联会话。

## 八、设置与数据

设置页可以调整外观、启动行为、关闭行为和本地数据。

- 导出数据前检查保存位置，避免把会话内容放入公共目录。
- 清除缓存或导入数据可能影响当前设备上的使用状态，请先备份重要内容。
- 连接外部服务时，仅授予完成任务所需的最小权限。

## 九、安全建议

- 不要在对话、脚本或配置文件中提交 API Key、访问令牌和账号密码。
- 执行删除、覆盖、发布、推送等高影响操作前，核对目标并确认授权。
- 第三方技能、插件和外援智能体可能访问文件或网络，请只使用可信来源。
- 发现权限异常、数据越界或未知网络请求时，立即停止相关任务并检查配置。
