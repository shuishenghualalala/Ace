# ChatGPT 渲染能力与 Ace 桌面对照

日期：2026-10-27。状态：核对完成；下方补齐计划未启动。

## 结论与证据范围

没有全部复刻。已完成的是桌面原生折线/分组柱状图、基础参数表单、本地计算、显式续问和本机恢复这条路径。此前实现验收通过不等于与 ChatGPT 全功能等价。

官方文档未提供可用于证明“全部覆盖”的私有前端组件清单。本记录区分 ChatGPT 产品能力、插件 UI 能力和 ChatKit 开发框架；不把 ChatKit 组件清单当成 ChatGPT 私有实现。实际可用性还受账户、平台和预览发布影响。

## Ace 代码核对

| 能力 | 当前状态 | 代码依据与边界 |
| --- | --- | --- |
| Markdown、代码、表格、公式 | 已有 | desktop/src/ui/markdown.ts；静态表格不是可筛选数据表 |
| 图解 | 部分 | features/mermaid-render.ts 和 conversation-renderer.ts；Mermaid SVG，不等于任意交互教学图解 |
| 原生数值图 | 部分 | features/native-visual.ts 和 crew/sites/native_visual.py：line/bar；数值 x；最多 4 系列、120 点；未提供饼/散点/面积/堆叠/热力图等原生类型 |
| 原生表单 | 部分 | range/number/text/select，最多 8 参数；select 为单选；没有日期、多选、复选、单选组、文件上传等协议节点 |

| 富卡片组合 | 未对齐 | 原生 spec 是固定标题/说明/参数/结果/图表/动作布局；没有递归卡片、列表、徽章、图片组合和多个语义动作 |
| 动作与更新 | 部分 | 明确按钮发送参数摘要；没有通用客户端/服务端动作路由、同一组件修订协议 |

| 展示模式 | 部分 | 聊天内联已实现；其他页面/侧栏不等于统一的组件全屏、画中画、轮播模式 |
| 状态 | 部分 | 原生描述随会话保存；输入按账户/会话/调用保存在本机；没有跨设备输入同步 |

## 下一轮建议计划（等待用户决定，不执行）

目标：把当前“图表+参数”协议扩展为常见任务可用的组合式富回复，同时保持普通场景无需生成 HTML/JS。

### 1. 组合卡片与表单

提供有界布局节点、列表、徽章、图片、多个明确动作；新增日期、复选、单选组、多行文本。扩展前后端校验、可访问标签和参数快照。
验收：实际模型在桌面回复中生成三个方案卡片并选择其一；生成含日期/复选/文本的需求表单，提交一条可读消息；非法值不能提交；重新打开保留输入；旧 v2 会话仍可读。

### 2. 图表与数据表

优先类别/日期轴、饼/环、散点、面积/堆叠，以及有界排序/筛选数据表。这是 Ace 的建议优先级，不声称它是官方穷尽图表类型清单。
验收：每种新增图由真实模型自然请求生成；数值与源数据核对；图表与表格共享同一数据快照；明暗主题/宽度变化/重开均通过；不创建网页项目。

### 3. 统一动作和组件版本

定义显式新增/修订、动作类型与状态；支持受控的原地更新，同时保留可追溯历史。为失败、加载、禁用提供统一反馈。
验收：同一个查询卡片翻页/筛选时只更新目标组件；重复事件不重复执行；跨会话/账户动作被拒绝；用户可以核对动作参数与历史版本。

地图、自由模拟、动画、全屏/画中画、跨设备状态等继续作为单独范围评估，不包含在上述三步的默认执行授权中。完整对齐不以“支持 HTML 沙箱”代替每一类能力的实际验收。
