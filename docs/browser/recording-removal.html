浏览器录制/回放功能移除记录

更新日期：2026-09-17

变更目标

移除会干扰内置浏览器和文件预览的录制、编译、安装与回放链路，让浏览器宿主只承担正常的页面导航、自动化、下载和预览。

已移除

层级变更
工具与技能删除录制控制、录制编译、回放工具及 record-to-skill 技能。
运行时删除浏览器面板的录制控件、录制事件转发，以及宿主的录制控制和原子回放 RPC 入口。
测试与文档删除录制/回放专属测试和过时设计文档，更新 Browser 模块索引。

保留能力

  • 正常浏览器自动化：导航、快照、定位、点击、输入、弹窗、标签页、下载和调试信息。
  • 文件预览：HTML artifact 的安全加载、导航和面板展示链路不受影响。
  • 跨平台实现：变更只移除功能入口与事件链，不依赖操作系统专属删除逻辑。

数据说明

本次没有删除用户已有的本地录制目录或文件；只移除了继续创建、编译和回放它们的代码入口。

验证

桌面端 TypeScript 类型检查通过；Python 源码编译检查使用项目环境执行。默认系统 Python 3.9 不满足项目的 Python 3.12 要求，因此不作为验收环境。
