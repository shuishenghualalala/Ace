两张图的对照要点

现状目标
功能怎么接入改 build_app()、handle()、sidebar-nav.ts 四个中心向 Registry 注册贡献，中心零改动
核心与业务的关系互相 import（双向）核心只依赖契约层（单向向下）
mode 是什么核心枚举里的特权名单Driver Registry 里的开放标识
功能间协作external/store.py 直接 import Team 类型经 Service Definition（Catalog），无互相 import
拆 Wiki 出去存储/Agent/API/UI 分散多处，等于重写换 Remote Provider + 宿主接线，业务逻辑不动
