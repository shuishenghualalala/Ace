1. 验证目标

  • 旧目录插件不改入口即可获得 Feature Generation 与 Scope 所有权。
  • 第 N 项注册后失败，前 N-1 项与异步资源全部回滚。
  • 重复 discovery 不重复 Tool、Hook、Skill 或后台资源。
  • 停用先隐藏贡献，再等待异步资源；清理失败尝试其余项并明确报告。
  • Browser 的真实五工具、Skill Root 和 Manager disposer 属于同一 Scope。
  • 应用关闭通过插件 Scope 释放 BrowserManager。

3. 新增回归场景

  • 安装失败：Tool、Hook、Command、Skill Root 与异步 Resource 无残留。
  • 重复发现：旧 Scope 进入 Disposed，新记录从 Generation 2 激活。
  • 慢清理：Tool/Hook 已不可见时 unload 仍保持等待，完成后才返回成功。
  • 清理异常：健康 disposer 仍执行，Feature 进入 Failed 并保留失败标签。
  • Browser：五个工具先撤销，Manager 的异步关闭完成后插件才变为 disabled。

4. 跨平台说明

同步宿主兼容桥使用标准线程和独立 asyncio loop，不使用嵌套 loop、fork 或 Unix-only API；异步宿主直接 await 同一 Runtime。
