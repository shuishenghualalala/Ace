生命周期核验要点

  • install 先登记 manager.stop_all() RESOURCE 相 disposer，再装配贡献；host 绑定在 CONTRIBUTION 相清除，消费者立即 fail-closed。
  • LogoutCoordinator 经 channels_service_getter 获取 (service, lease)，操作结束即释放；draining 期间获取失败返回 None，不再启动或停止任何渠道。
  • crew.channel_manager / crew.delivery_router 为动态属性：显式注入优先，否则解析当前代 Channels Service；Feature 非 ACTIVE 时返回 None。

遗留边界（4D-2）

  • routers/channels.py 闭包仍持有候选实例，Feature restart 后需改为请求期动态解析或 Route Lease。
  • sender 注册分散在装配、路由与 Adapter 多处，待统一收拢到 Channels Service 消费侧。
  • 飞书 WS 守护线程热停、微信 fire-and-forget 任务跟踪、平台插件 stop_policy 重估，均待 4D-2 处理。
  • channels 包对 gateway 的 hooks/outbound/session_context 仍有少量依赖，后续评估是否下沉。
