导出一致性约束

  • 任务创建时冻结 owner、筛选条件、事件水位和时间点；TraceStore 分页与 event 查询应用水位，payload 通过受控引用和捕获时间截止。
  • 记录先写唯一临时文件；达到数量、时限或字节预算时在写下一条前停止，manifest 明确 partial_reason，产物始终不超预算。
  • 取消只设置 worker stop event；worker 在提交前清理临时文件，下载仅接受 completed 或结构闭合的 partial。
  • 下载权限重新校验 owner 和 developer access；桌面主进程使用固定 endpoint 与同目录临时文件，Windows 提交失败尝试恢复原目标。

未覆盖与已知风险

  • 本轮没有重新跑完整 Python 仓库回归，也没有做跨平台打包后的 Windows/macOS/Linux Gateway 真机 smoke；托管环境注入已覆盖三套打包启动路径和单元断言。
  • 没有运行 Playwright/electron 视觉回归或大规模（10k/1M traces）性能基准；桌面行为测试使用 happy-dom 的真实 DOM 事件与分页交互。
  • 仓库级 uv run ruff check crew 仍会命中既有的 crew/gateway/ws.py 未使用 get_skills（本轮未改无关文件）；本轮所有变更 Python 文件的 Ruff 检查通过。
