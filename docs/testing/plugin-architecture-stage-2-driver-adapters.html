3. 关键回归场景

  • 未启用 Team 时 Registry 不暴露 team；启用后由 Team Adapter Generation 提供。
  • Team 请求进入旧 Manager 前仍解析会话级 external_team_id。
  • dynamic_kanban 绑定到独立 Adapter Generation，并继续产生最终响应。
  • 关闭 App 后 team 与 dynamic_kanban 均不再可见。

4. 跨平台说明

测试不使用 POSIX signal、fork 或平台文件锁。Adapter 注册、异步生成器、Lease drain 与并行关闭走 Python 3.11+ 的跨平台 asyncio 语义。
