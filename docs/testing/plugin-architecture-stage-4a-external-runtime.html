插件架构阶段 4A-2 · 外援 Provider / Run 生命周期

分支：refactor/plugin-architecture-stage-0 · 日期：2026-09-09 · 编码：Luna 子 Agent · 验证：独立测试 Agent + 主 Agent 收口

验证目标

  • product.external-agents Generation 统一拥有 Catalog、AdapterRuntimeProvider 与 DelegationService，并提供 external-agent-catalog、agent-runtime-provider、delegation 三个 Service。
  • 生产 ExternalExecutor 经 external_services_acquirer 在同一 Generation 内同时取得 Catalog 与 Delegation，不直接调用 Adapter；Run 在整个流期间持有 Generation Lease。
  • 部分消费、取消与 Feature 停用均释放 Adapter 流与子进程；停用先关闭准入（delegation.close，Contribution 相）再关闭 Provider/Catalog（Resource 相）。
  • Factory 创建的 Catalog/Provider 具备完整代际所有权：激活失败关闭候选资源，更新（restart）启用全新 Provider 与 Catalog。
  • Team 不再持有裸 Store：经 external_store_provider 动态解析当前代 Catalog；Gateway runtimes/sessions 路由 Registry 优先解析，宿主字段仅作迁移期回落。

生命周期核验要点

  • DelegationService.submit 为每个 Run 单独获取 Generation Lease 并 detach owner，由取消 watcher 协调；Run 完全关闭后才释放 Lease，避免长请求任务被提前中断。
  • AdapterRuntimeProvider.close 取消全部在途 Run；_AdapterRun 保证流迭代器恰好关闭一次、不可重复消费。
  • 激活失败路径：候选 Provider/Catalog 在 install 抛出时被 _close_owned 关闭，Runtime 回滚后无半激活状态。
  • 停用后 host.external_agents 由 binding disposer 清空；Gateway 路由在 Registry 缺失时 fail-closed（外部智能体存储未初始化）。
