  • product.dynamic-kanban Generation 统一拥有 Manager、SQLite Store、运行任务与 mode=dynamic_kanban Execution Driver、REST Route（Route Registry 挂载，gateway 中心装配删除直挂）。

  • restart 更新分配全新 Manager/Store 且保留历史行业务行；Manager 构造失败时候选 Store 被关闭、Feature 进入失败态。

生命周期核验要点

  • install 先注册 manager.close disposer 再装配依赖贡献，任何激活失败都走 Runtime 正常回滚；host 字段由 binding disposer 清空。
  • DynamicKanbanConsumer 仅暴露 TeamPlanStore 使用的 Store 方法，每次调用 acquire/release 同代 Lease；停用后调用抛 FeatureLeaseUnavailableError。
  • 后台化执行的 consumer Task 经 scope.create_task 归属 Generation；manager.close() 先 request_stop 全部 runtime，再取消后台任务、关闭 Store。
  • Execution Driver Registry 在流结束后兜底 aclose 内部生成器，保证部分消费不泄漏运行任务。
