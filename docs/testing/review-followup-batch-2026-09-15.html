S1 · UI 异步请求所有权收口

缺陷：① refreshKanbanStatusOnly() 只校验会话、不校验安装代——同会话卸载重装后旧代轮询响应仍回写 latestStatus/DOM，旧代终态还会经 stopKanbanStatusPolling() 停掉新代定时器（句柄模块级单一份）；② refreshTeamCollaborationBoard() finally 无条件释放占用——旧代请求结束会误删新代同会话请求的占用标记，后续刷新并发乱序回写。

修法：轮询 tick 回调闭包捕获发起代数，refreshKanbanStatusOnly(sessionId, generation) 入口与 await 返回后双重代际+会话校验；Team 侧 refreshInFlight 改 Map<sessionId, token>（自增 token），finally 仅在仍持有自己 token 时释放。

测试：新增 7 用例（kanban 4 + team 3），全部确定性 deferred 屏障、零固定 sleep。修复前 4 红（clearInterval 被旧代多调一次、第三次刷新绕过占用）→ 修复后全绿；stash 基线核验 18/18 证明红均由缺陷引入。

S2 + S2b · 配置操作完整事务

已复现缺陷（审查方经真实 Router + Config 注入 YAML 写入失败）：MCP PUT 500 后内存新 command / 磁盘旧 command；DELETE 500 后内存无 server / 磁盘保留；根因是调用方先改内存后持久化，_atomic_write_yaml 只管文件替换与 raw_config 发布顺序。同型核查：模型 profile（use/add/update/remove 四入口先激活/增改/pop 再 persist）与 evolution（misc.py / cli/knowledge.py 先赋值再 persist）存在同样分叉，已由 S2 固化为两个 xfail 证据测试。

修法：config.py 新增统一写入边界——_commit_mcp_servers(candidate) 与 _commit_model_profiles(candidate, *, active_model_id, default_model_id) / set_active_model / set_evolution_config，顺序契约：候选值（副本计算，不碰已发布内存）→ 前置校验 → _atomic_write_yaml 原子落盘 → 磁盘成功后发布内存。Router（mcp_servers / misc）与 CLI（integration / knowledge）全部改走事务入口；持久化失败先于任何运行资源操作返回（provider 重建 / MCP 子进程启停 / env 与凭证清理只在成功后）；"已保存但连接失败"如实上报、不回滚伪装。遗留两步式入口（set_mcp_server / persist_model_profiles 等）仅为未迁移调用方保留并 docstring 标注。owner 语义：全局事务只写 config.yaml llm 段，owner overlay 按文件天然隔离（新增用例锁定 acc-a 失败不影响 acc-b）。顺带修复"删除激活模型后切换不落盘"的隐性缺口。

测试：HTTP+CLI 真实入口注入 yaml.safe_dump OSError 与 Path.replace 失败，核对业务字段 + raw_config + 磁盘回读 + 运行管理器调用次数；两个 xfail 转正；模型四操作 + evolution 两入口 + owner 隔离 + 失败重试共新增约 30 用例。修复前红（HTTP 5 failed + 2 xfailed）→ 修复后 242 + 31 + 77 passed（分层回归）。

S3 · UI 安装失败的事务回滚

缺陷：installTeamKanbanBoards() 两板装完才存总 disposer；initKanbanBoard() 逐个注册、全成才发布自己的 disposer——中途注册冲突时贡献残留、重试继续冲突、总 disposer 未建立。

修法：两级事务——单 Feature 的 create*InstallTransaction 即时收集每步 disposer，失败逆序撤销本次贡献（每个清理单独兜底、互不阻断），成功发布幂等 disposer 复用同一清理链；组合层 applyBoardCapability 逐板 try/catch 隔离，一块失败不牵连另一块、不上抛，初始安装与能力翻转同路径，故障解除后翻转/重试补装。顺带修复 bindTaskBoardResize disposer 中 mousemove 移除错绑的既有 bug。S1 的代际计数器/token 语义完全保留（失败回滚不走 dispose 路径、不额外递增代际）。

测试：6 个红用例（组合层隔离 2 + 单 Feature 回滚 4）由中断的前一 agent 写好、本 agent 核对断言零修正后修实现转绿；6 测试文件 69/69 全绿。
