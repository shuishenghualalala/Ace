本分支引入的失败（待修复，不在本文档批次范围）

以下 3 个用例在基线 61d1c8b 通过、自本分支首个 commit 71513d9 起失败（逐 commit 二分确认）：

  • tests/test_wiki_learning_plugin.py::test_plugin_learning_flow_captures_answer_privately
  • tests/test_wiki_learning_plugin.py::test_assessment_is_idempotent_per_request_and_not_same_turn
  • tests/test_wiki_learning_plugin.py::test_activity_rejects_nested_private_answers

根因：71513d9 把同步 hook 回调挪进 asyncio.to_thread 后，plugins/wiki_learning 的同步 pre_llm_call 钩子内对 ContextVar（plugins/wiki_learning/context.py 的 _active_kb_id / _latest_user_text）的 .set() 发生在 to_thread 的上下文副本里，无法回传事件循环侧调用方；后续学习工具执行时 active_kb_id() 读到默认值，抛「当前知识库上下文缺失」。修复方向（供后续批次）：hook 侧有状态回传需求的插件改经返回值/消息传递状态，或在 manager 侧为同步回调保留调用方上下文合并语义。
