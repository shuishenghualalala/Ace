生命周期核验要点

  • Router handler 经 crew.channel_manager 动态属性解析，Feature restart 后自动指向新代实例，不持有旧引用。
  • CLI _channel_manager 不再本地 new，Feature 非激活时抛 CliError("渠道服务未就绪", exit_code=503)。
  • 飞书 stop() 设置 _ws_stop_event 并尝试 ws_client.stop()；_serve_ws 线程等待事件后调用 stopper 并 join runner（最多 5 秒）。
