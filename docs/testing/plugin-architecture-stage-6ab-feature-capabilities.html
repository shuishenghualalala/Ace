阶段 6AB · UI Feature 运行时能力状态源

2026-09-14。Team/Kanban 双端 reducer 已具备 init/dispose，但缺少可靠的功能启停状态来源，UI 无法据以动态装卸。本片交付后端精简能力快照与双端可选类型，为后续 UI 动态装卸切片提供统一状态源；设计与决策见 ADR-0040。

处置

  • Runtime 快照：FeatureRuntime.capability_snapshot() 按 Feature ID 返回 state / available / generation 三字段。可用性对应当前有效 Generation 的请求准入——Scope 处于 active 才可用；drain、失败、停用立即不可用；replace 候选安装期间仍投影正在服务的旧代；读取不创建 Lease、不改变生命周期，也不导出错误、配置修订等诊断明细。
  • Gateway 投影：config_body() 经 crew.plugins.feature_runtime 读取快照，新增 feature_capabilities 字段；经 getattr 链探测，无 Runtime 的兼容测试宿主返回空映射，现有 Wiki、外援字段契约不变。
  • 双端类型：Desktop BackendConfig 与 Web AppConfig 各新增可选 feature_capabilities 字段与 FeatureCapability 类型，仅类型承接、无行为改动；Desktop/Web 对该状态源的消费（reducer 动态装卸、board hooks、页面投影）属后续切片，本片不宣称 UI 生命周期闭环。
