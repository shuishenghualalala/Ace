4. 时序确定性与跨平台检查

  • 批量爬坡/退避用可注入假时钟断言（launch 时刻序列 [0, 0, 1, 2]、重排间隔 ≥ backoff_base），不依赖真实墙钟。
  • 实现只用 sqlite3 / asyncio / pathlib；无信号、无 fork、无 Unix 权限位、无平台路径拼接。
  • 四态路由对状态观测失败一律回退 IDLE（等同旧"只入队"行为），不会因观测面异常丢通知。

5. 结论

任一 run 的结局可只读日志复算（折叠函数为唯一推导入口并有冲突改写用例）；进程重启后 descriptor/edges/runs 可读；批量调度有确定性时序测试；深度记账单调且默认行为与旧版逐字一致；通知四态路由保住三条硬不变量。
