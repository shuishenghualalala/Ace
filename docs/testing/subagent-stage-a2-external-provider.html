4. 插件化验收结论

外援接入只修改其自身 Feature 与 Provider 适配器；Subagent Core 只新增通用 resolver 扩展点。Provider 注册、撤销和在途运行清理由 Feature Generation/Scope 拥有，模型工具没有外援专有参数或分支。进程内与进程外 Provider 同时满足同一服务契约。

5. 跨平台检查

新增实现只使用 Python 值对象、asyncio、Feature disposer 与既有 Runtime adapter；不引入 signal、fork、Unix 权限位或平台路径拼接。外部命令的跨平台差异继续封装在既有 adapter/runtime registry 内。
