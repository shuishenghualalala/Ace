远程化前置发现（供 Remote Provider 切片处理）

  • KnowledgeSourceFile.content: bytes 无法无损 JSON round-trip，远程化前需 base64 显式编码或元数据/内容双通道。
  • KB 删除后读取得到静默空视图（惰性重建空目录），协议层无法区分"空库"与"已删库"——远程实现需先定语义。
  • ingest 取消语义不一致：analyze 期间取消返回 issues=["已取消"]，检查点之间取消抛 CancelledError。
  • source_file 与 source_files 的 location 语义不一致（标题 vs 绝对路径）；绝对路径远程化后无意义。
  • 教程库播种是 list_knowledge_bases 的惰性副作用，全新 owner 列表无 default。
