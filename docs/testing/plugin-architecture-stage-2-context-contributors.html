3. 关键场景

  • 低优先级数字先执行；同名参数由后执行 Contributor 确定性覆盖。
  • 可降级超时进入结构化 failures；失败关闭贡献抛出稳定错误。
  • 贡献执行期间开始 drain：新请求不再发现贡献，旧请求完成后 Scope 才停止；Browser Handler 固定使用所属 Generation 的 Manager。
  • 真实 App 请求同时解析工作空间路径和浏览器标签页，并把通用 fragment 交给 Agent。
