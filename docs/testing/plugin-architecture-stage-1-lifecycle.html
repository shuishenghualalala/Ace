分支：refactor/plugin-architecture-stage-0 · 日期：2026-09-02

1. 验证目标

  • 一代 Feature 的全部运行时贡献拥有统一、可诊断的所有权。
  • 部分安装失败能按后进先出顺序完整回滚。
  • 异步清理真正完成前，Feature 不报告已停止。
  • 重复或并发释放不重复执行 disposer，单项失败不阻断其余清理。

3. 覆盖的不变量

  • STOPPING 状态先于清理开始设置，此后注册立即失败。
  • 释放顺序严格为注册顺序的逆序；异步 disposer 使用同一序列等待。
  • 清理错误保留 Feature Generation、注册标签与原始异常。
  • 安装异常与回滚异常分别保存在 FeatureActivationError 中。

4. 跨平台说明

测试不依赖信号、Shell、路径分隔符或操作系统事件循环扩展；生命周期语义在 Python 3.11+ 的 macOS、Linux、Windows 上一致。
