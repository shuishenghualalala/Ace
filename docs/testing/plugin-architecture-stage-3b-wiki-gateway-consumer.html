验证目标

  • Service Registry 的 acquire、release、drain 和新旧 Generation 选择属于同一租约语义。
  • 全部 /api/wiki/* 在 Knowledge Service 不可用时统一返回 503；正常请求按次解析当前 Generation。
  • 在途 API 请求阻止旧 Provider 提前关闭；外部注入 Service 在无产品记录的嵌入宿主中仍可消费。
  • 附件捕获持有同一 Service/Lease 解析显式或会话 KB，drain 竞态不回落 default，停用后不捕获。
  • Gateway 不再导入 Wiki Store、Parser、私有组件或本地目录 API；页面搜索、上传和 Owner/KB 行为保持回归。
