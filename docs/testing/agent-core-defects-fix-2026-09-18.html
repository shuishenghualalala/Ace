设计边界

  • 标准 Gateway agent turn 的整回合 deadline 由 TaskRuntime 负责；executor 的配置只服务于脱离 Gateway 的直接调用。
  • 工具超时不会自动重放写操作；副作用未知时保留 unknown，由用户或下一回合决定。
  • WS 断开不会推断 Gateway 进程死亡；进程状态只由 supervisor 生命周期事件更新。
