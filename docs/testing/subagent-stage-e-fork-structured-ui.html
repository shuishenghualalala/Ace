人工检查点

  • fork Provider 不调用平台专有进程 API，只使用 asyncio、SessionStore 与 pathlib/值对象。
  • structured_output 使用 Feature-owned 注册，普通主 Agent 的 subagent tool policy 会过滤 subagent.output。
  • 生命周期事件未知版本仍走既有 registry 的安全忽略路径，多次 React effect 切换由 disposer 回收。
  • 活动卡只读显示当前会话，API 返回的 items/runs 与生命周期状态按子智能体 id 归并；无记录时不占用聊天布局。
  • 活跃子智能体兼容视图按 owner_account_id 过滤，验证同一 session id 的跨账号记录不会互相泄露。
