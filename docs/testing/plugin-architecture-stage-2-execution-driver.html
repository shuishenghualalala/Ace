1. 验证目标

  • 开放 mode 可注册、解析、分派和撤销，不需要修改 CrewApp.handle()。
  • Driver Contribution 受 FeatureScope 所有，Activating 不可见，新 Generation 提交后原子接管。
  • 活跃 Driver 流持有 Lease，drain 完成前不释放所属 Generation。
  • 默认 Agent 经 Registry 执行，旧 agent 和新 agent.default 均可发现。
  • 未注册 mode 返回稳定 capability_unavailable，不回退默认 Agent。

3. 关键回归场景

  • 同一 mode 的无关 Feature 重复注册会失败，并点名当前所有者 Generation。
  • 旧 Driver 服务请求期间开始 drain：Registry 立即拒绝新请求，已有流完成后才清理。
  • Feature 安装自定义 feature.echo 后，App 无需新分支即可执行；停用 Feature 后返回标准 unavailable。
  • 目录插件注册 plugin.echo 后可直接 dispatch；卸载插件后 mode 随 Token 消失。
  • 既有 Dynamic Kanban 和外部智能体关闭策略保持原行为。

4. 跨平台说明

测试不使用 POSIX signal、fork 或平台文件锁。注册、分派、异步生成器与 Lease drain 全部走 Python 3.11+ 的跨平台 asyncio 语义。
