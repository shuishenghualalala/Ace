范围与归属

补齐阶段 5 的明确要求：Wiki 禁用时不注册 Wiki 事件处理器。沿用已有能力状态来源，处理器由 Feature 安装期持有，页面切换不撤销；能力停用与宿主卸载才释放注册。关闭功能不删除历史数据或取消已发起的后端业务。

Desktop 与 Web 开发分别由独立子 agent 执行，另一子 agent 独立编写及执行行为测试。主 agent 负责架构审查、记录和逐片提交。本批未修改 Team/Kanban 能力策略；Web 宿主注册方式调整后，其原有事件处理经验证继续有效。
