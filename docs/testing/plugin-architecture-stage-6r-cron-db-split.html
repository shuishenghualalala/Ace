阶段 6R · 拆库试点 cron.db（ADR-0038 / P1-1 首切片）

2026-09-12。cron 两表（cron_jobs、cron_job_runs）迁入独立库 crew_data/cron.db，建立 copy-on-first-activate 迁移机制与跨库 claim-legacy。决策记录：ADR-0038。

机制

  • copy_legacy_feature_rows(legacy_db_path, target_conn, tables)（crew/state/schema_version.py）：旧库缺文件/缺表跳过、目标库已有行跳过（幂等）、整表复制在 SAVEPOINT 内原子（失败整体回滚，autocommit 与 BEGIN IMMEDIATE 两种上下文均验证）；旧表保留在 crew.db 作回退备份。
  • 顺序保证：ensure-schema → stamp_baseline("cron", v1) → copy gate（store 构造器内，legacy_db_path 参数显式传入）。
  • 配置：cron_db_path 顶层键（memory_db_path 先例），build_app 消费点 _resolve_cron_db_path() 归一——顺带根治了直接构造 Config 时 CWD 相对路径污染的一类隐性 flake。
  • claim-legacy 跨库：_migration.py 表清单带库归属，legacy_owner_scan_targets() 产出路径→表映射，CLI 与 startup 巡检均映射驱动；cron 智能回填改双连接参数化（同库时同一连接，无 ATTACH）。
