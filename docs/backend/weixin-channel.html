W微信渠道（weixin）设计文档

个人微信 · 腾讯 iLink Bot API 长轮询 · 2026-08-02 建立

1. 定位

  • 接入个人微信（区别于企业微信 wecom）：基于腾讯 iLink Bot API，长轮询收消息，无需公网 webhook。
  • 凭证通过扫码登录获得：桌面端内置扫码 / 终端 crew weixin-login，token 持久化到 {crew_home}/weixin/accounts/。
  • 复用既有渠道插件范式（plugins/platforms/* + Channel 接口 + PlatformRegistry），与飞书渠道同构。

2. 关键文件

3. 架构与数据流

3.1 入站（长轮询）

start() → poll_loop() 循环 get_updates(sync_buf)
  → 每条 msg: 解析文本/媒体 → 去重 → decide_access(dm/group 策略)
  → 下载媒体（AES-ECB 解密 → cache 到 files_dir）
  → _handle(): 按 chat 串行 → Envelope 投递内核 → 流式收集 final/error → 回包

3.2 出站

reply → apply_text_filters → 检测 [FILE:路径] → 发文件(加密 CDN 上传)
  → 否则 split_text_for_delivery 分块 → send_message(context_token 会话续传)

3.3 桌面端扫码登录

桌面「扫码登录」→ POST qr-login/start → 返回二维码 SVG → 展示
  → 轮询 POST qr-login/status → confirmed 时 save_account + 自动填 accountId 并 connect

4. 配置项

4.1 启用

config/config.yaml:
plugins:
  enabled:
    - weixin
channels:
  weixin:
    enabled: true
    accountId: "ilink_bot_id"   # 扫码登录后自动填充

4.2 环境变量（extra 与 env 均可）

变量默认说明
WEIXIN_ACCOUNT_ID—iLink 机器人 ID（必需）
WEIXIN_TOKEN—iLink token（必需；也可扫码持久化后省略）
WEIXIN_BASE_URLhttps://ilinkai.weixin.qq.comiLink API 基址
WEIXIN_CDN_BASE_URLhttps://novac2c.cdn.weixin.qq.com/c2c媒体 CDN 基址
WEIXIN_DM_POLICYopen私聊策略：open / allowlist / disabled
WEIXIN_GROUP_POLICYdisabled群聊策略：disabled / open / allowlist（默认关，见限制）
WEIXIN_ALLOWED_USERS—私聊白名单（逗号分隔）
WEIXIN_GROUP_ALLOWED_USERS—群聊白名单
WEIXIN_TEXT_CHUNK_LIMIT2000单条文本上限（iLink 约 2048）

5. 依赖

pip install .[weixin]   # aiohttp + cryptography + qrcode

6. 已知限制

扫码登录连接的是 iLink 机器人身份（形如 xxx@im.bot），普通微信群事件绝大多数账号类型不会推送给机器人，只有私聊稳定可用。 WEIXIN_GROUP_POLICY 仅在 iLink 真正返回群事件时生效；群消息不生效属于 iLink 侧限制，非渠道代码问题。

7. 测试

  • 协议：AES 加解密、入站解析、文本分块、账号/context-token 持久化、媒体项构造。
  • 适配器：去重、_handle 回包、访问控制拦截、send_to_target。
  • 扫码接口：start 返回二维码、confirmed 持久化账号、redirect 跟踪、失败 pending。
  • 注册：插件加载后 platform_registry 可用/已配置。
