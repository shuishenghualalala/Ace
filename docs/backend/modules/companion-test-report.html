验证说明

本机自动化已覆盖 WebRTC 的实际建链与文件字节传输，但无法代替两台真实设备的 BLE 权限和 NAT/防火墙矩阵。默认 Python 3.10 不满足项目既有 enum.StrEnum 要求，完整 E2E 使用仓库 .venv 的 Python 3.11.11 运行并通过。

仍需真实设备验证

  • macOS / Windows / Linux 的 BLE 权限、扫描、互连和休眠恢复。
  • 两台电脑处于不同网络时的 STUN 直连、TURN 回退、企业防火墙与 4 MiB 边界。
  • 跨系统文件名、接收弹窗、拒绝、BLE 断线和系统睡眠中的失败反馈。
  • 正式发布前的 BLE 应用层 E2EE 与身份指纹确认。
