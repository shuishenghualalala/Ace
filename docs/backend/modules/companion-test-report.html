2026-08-28 macOS 双机文件信令修复

问题修复与验证
接收确认后没有文件日志确认 file.webrtc_offer 已完整到达接收方，但 Mac Peripheral 回传 Answer 时忽略了 CoreBluetooth 队列满状态，较大的 SDP 分片会静默丢失。
可靠回传Apple OutgoingMessage 使用 Indicate；队列满时等待 peripheralManagerIsReadyToUpdateSubscribers 并重试当前帧，Offer/Answer 使用保守分片节奏。Windows/Linux 路径保持原策略。
诊断覆盖增加 Offer、Answer、ICE、DataChannel 与 Peripheral 分片阶段日志，不输出 SDP 内容，可直接定位信令在哪个阶段停止。
测试结果Rust 63 项、Clippy、Desktop Nearby 48 项、TypeScript 类型检查和开发构建通过；真实 macOS ↔ macOS 双向文件等待新构建实机验收。
