Acrew/state

State 状态层：配置加载/写回、API Key 凭证库、Crew Home 与 owner 运行时目录、会话/工作区存储、日志。

1. 职责

  • 持久化与配置事实来源：config.yaml（结构化配置，不含密钥）+ .env（环境变量密钥）+ credentials.json（模型 API Key 凭证库）。
  • 目录布局：CREW_HOME（默认项目根 .crew/，打包环境 ~/.crew/）与 owner 运行时 home（accounts/<owner>/）。
  • 不做：业务逻辑、LLM 调用（装配在 crew/app.py）。

4. 数据模型与接口

模型 API Key 解析链（resolve_profile_api_key，所有 profile 构建点统一走它）：

凭证库[profile_id]（owner 作用域，credentials.json）
  → api_key_env 环境变量（env_map 优先于进程环境）
  → （仅全局/共享层）CREW_API_KEY 兜底

写路径（crew/app.py 模型 CRUD）：默认 store_key(owner, profile_id, key)； 显式传 api_key_env 才写 .env——当目标变量名被其它 profile 引用且已有不同旧值时， 必须 payload 带 overwrite_shared_key: true 才放行（防"所有 apikey 变成最新的 apikey"）； remove_model 同步清理凭证库条目。
