2. 推荐阅读顺序

第一次理解整体运行链路，建议按以下顺序阅读：

  1. Core：先固定 Envelope、Message、接口，确保所有模块说同一种语言。
  2. State + Provider + Tools：补齐 Agent 需要的历史、模型和行动能力。
  3. Agent：把历史、记忆、插件、模型、工具串成单智能体循环。
  4. App + Gateway/CLI：用 app.py 做装配，入口层只负责协议转换。
  5. Team + Tasks + Cron：在单 Agent 基础上增加多智能体协同、任务看板和自动化。

3. 文档维护约定

  • 新增模块时，先在上方表格登记，再复制 _template.html 创建 <module>.html。
  • 每次改动后端模块代码，若涉及职责、接口或新增子功能，同步更新对应模块文档的「功能拆解」「关键文件」「数据模型与接口」「当前存在的问题 / TODO」「变更记录」。
  • 索引页只负责导航，不再堆积详细变更记录；历史变更已下沉到各模块文档。

4. 与 Crew 的差异

本索引对应 Ace（Crew 开源版）实际代码。Ace 移除了 api 模块（开源版脱敏移除），保留 sites、work、companion、notifications 等 Ace 特有模块；browser 与 security 因涉及独立工程，文档独立成册。
