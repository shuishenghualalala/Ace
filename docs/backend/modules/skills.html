Skill 子系统

crew/agent/skills.py · 目录发现、加载、安装与安全校验 · 2026-08-02 建立

1. 定位

Skill 是封装在目录（含 SKILL.md）中的可复用 Agent 能力。对话中通过 /skill名 激活，由 resolve_skill 解析、build_skill_activation 构建指令注入当前轮。

系统分两层：扫描层决定对话中可调用；可安装源仅在技能页展示，未安装不可调用。

2. 目录分层

2.1 扫描层（scan_skills，决定可调用）

层目录常量
内置<repo>/crew/skills/get_builtin_skills_dir()
插件插件声明的 skills/ 根get_plugin_skill_roots()
用户get_crew_home()/skills/get_user_skills_dir()

覆盖优先级：user > plugin > builtin（用户覆盖同名插件/内置）。

2.2 可安装源（仅展示，未安装不可调用）

源目录常量安装方式
Optional<repo>/optional-skills/get_optional_skills_dir()原子复制（copytree）
本地~/.agents/skills/get_local_skills_dir()软链（symlink）

本地源是跨 agent 共享的 skill 仓库（如 npx skills add larksuite/cli 安装的飞书 skills），默认 ~/.agents/skills，可用 env CREW_LOCAL_SKILLS_DIR 覆盖。不扫 ~/.claude/skills（其内容为软链到 ~/.agents/skills，会重复）。

3.1 Skill 读取生命周期

skill_view(name) 返回主 SKILL.md 或 PACKAGE.md 时，结果标记为持续指令；后续即使出现大量终端、Canvas、Widget 等工具调用，也不会被日常微压缩清除。skill_view(name, file_path) 返回引用文件时按资源处理，同一 Skill 路径只保留最近版本。

上下文接近上限、必须生成完整摘要时，最近 5 个已加载 Skill 会作为受保护附件恢复；单 Skill 最多保留 20000 字符，总附件另有上限。恢复内容来自会话内已经授权返回的结果，不会在压缩阶段直接读取文件系统。

skill_view 同时纳入只读工具防循环：同一 name/file_path 连续返回相同内容会先提示模型使用现有结果，达到配置阈值后停止重复调用。

4. 安装机制

4.1 Optional（仓库随附）

install_skill 从 list_optional_skills() 解析源，_install_skill_tree 在 user dir 内分阶段 copytree + _validate_skill_tree 校验后同文件系统 rename 原子发布。失败回滚 tombstone。

4.2 本地（软链）

optional 找不到时 fallback list_local_skills()。_install_local_skill_link 在 user dir 建 os.symlink 指向 ~/.agents/skills/<name>，源更新自动同步；卸载仅 os.unlink 软链，不递归删源。

get_crew_home()/skills/lark-doc  --symlink-->  ~/.agents/skills/lark-doc

list_skills 的 is_user 判定用 resolve_skill_path：软链 skill 因受信任根放行通过，正确标记 source=user（不误判 builtin）。

5. 安全校验（核心）

resolve_skill_path(path, allowed_root) 解析路径（跟随软链），证明最终目标在 allowed_root 内，越界则抛 SkillPathError。被 scan_skills / _scan_dir / _iter_skill_files / _validate_skill_tree / read_skill_text / uninstall 全链路调用。

软链放行边界（本地 skill 关键）：本地 skill 软链指向 ~/.agents/skills（在 user dir 外），默认会被判越界、全链路加载失败。为此引入 _trusted_link_target_roots()（返回 [~/.agents/skills]），resolve_skill_path 越界时追加检查——resolved 落在受信任根内则放行。
  • resolve 递归跟随所有软链到最终真实路径，~/.agents/skills 内的二级逃逸软链（如指向 /etc、~/.ssh）最终 resolved 落在外部仍被拒。
  • skill 内部若有越界软链，_walk_contained 记录 finding，_validate_skill_tree 失败，安装被拒、已建软链由调用方清理。
  • 卸载时 _is_trusted_local_link 区分本地软链（os.unlink 删链）与普通目录 / 不受信软链（拒绝，防 rmtree 删源）。
一处改动打通全链路：仅在 resolve_skill_path 加受信任根放行，scan/validate/view/uninstall 自动接受本地软链 skill，无需逐点打补丁。安全边界由"只放行 ~/.agents/skills 这一个根"保证。

6. API（crew/gateway/routers/misc.py）

路由说明
GET /api/skills已安装 + 内置（list_skills）
GET /api/skills/store{installed, optional, local, evolution}
POST /api/skills/{slug}/install安装（optional 复制 / 本地软链）
DELETE /api/skills/{slug}卸载（目录 rmtree / 软链 unlink）

审计日志 get_crew_home()/logs/global-skills-audit.jsonl 记录所有 install/uninstall（source 字段自由字符串，本地安装传 desktop-api 等，无需 schema 改动）。

7. 数据流

~/.agents/skills/<name>/SKILL.md
   │  list_local_skills()（_parse_listing_skill，source=local）
   ▼
/api/skills/store { local[] }  ──►  技能页「可安装」视图（本地徽章）
   │  install_skill(slug)  ──►  _install_local_skill_link
   ▼
get_crew_home()/skills/<name>  --symlink-->  ~/.agents/skills/<name>
   │  scan_skills() 加载（resolve_skill_path 放行受信任软链）
   ▼
对话中 /<name>  ──►  resolve_skill  ──►  build_skill_activation
