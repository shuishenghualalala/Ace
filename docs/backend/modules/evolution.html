Acrew/evolution

技能进化：轨迹提取、技能生成与优化。

1. Agent 装配

主 Agent 开启 agent.evolution.auto_trigger 后，正常结束的回合触发技能进化。auto_full_cycle 选择仅提取轨迹或继续优化和生成技能。visible 选择当前回合内显示进度，或者由应用共享队列在后台执行。

2. 后台队列

EvolutionQueue.enqueue 为有待处理任务的会话建立队列和 worker。同一会话按加入顺序执行，不同会话可并行。worker 通过 asyncio.to_thread 运行同步管理器。队列排空后，worker 在同一个事件循环执行段内注销自己的队列和注册。会话再有任务时新建 worker。

SQLite 在提交当前回合的首条用户消息时一并返回 history_incarnation。队列、worker 和待取结果按账号、会话 ID 和该代次隔离。worker 执行前和交付结果前核对原代次，后续回合也核对后才取出结果。应用关闭时等待已接纳的工作，等待期间接纳的新任务也会纳入回收。

前台阶段进度和当前代次的后台结果通过已有 status 帧传输，保留阶段或结果数据，并继续发送正常回合终态。

3. 关键文件

文件作用
crew/evolution/queue.py后台任务排序、队列和 worker 生命周期、结果交付。
crew/evolution/evolution_manager.py组装轨迹提取、技能优化和生成。
crew/agent/runtime.py按回合结局、会话和配置触发进化，向会话输出后台结果。
