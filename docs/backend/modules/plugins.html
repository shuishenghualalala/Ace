Acrew/plugins

Plugins 插件：可逆注册 Feature 能力、工具、Skill 与运行时钩子。

1. 职责

  • 向插件提供受控注册上下文，并在启用/停用时管理插件贡献的工具与钩子。
  • 插件工具沿用核心 Registry 契约，可声明结果在 Agent 上下文中的生命周期。

2. 功能拆解

按子功能或核心流程拆解，这是本模块文档的重点。

子功能说明状态
工具注册PluginContext.register_tool 注册并记录插件贡献，停用时可撤销。已落地
结果生命周期插件可声明 temporary/resource/instruction/important；省略时安全默认 important。已落地

3. 关键文件

文件作用
crew/plugins/manager.py插件发现、状态管理、PluginContext 和贡献撤销。

4. 数据模型与接口

PluginContext.register_tool(
    name, toolset, schema, handler,
    result_retention="important",
    result_identity_fields=None,
    result_policy_resolver=None,
)

资源工具应提供稳定 identity；根据 action 同时提供读写能力的工具可通过 resolver 动态返回策略。未声明的旧插件保持兼容，并按重要结果保护。

5. 当前存在的问题 / TODO

  • 外部 MCP 协议当前不携带 Ace 生命周期元数据，因此默认按重要结果保护。

6. 扩展点

  • 新增插件工具时在插件注册处声明结果语义，不向 Agent 压缩器添加插件工具名判断。
