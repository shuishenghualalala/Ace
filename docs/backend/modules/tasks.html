子功能说明状态
TaskRuntime任务运行时：任务创建/状态流转/活动保活/终态收敛/重启对账，SQLite 持久化（RLock + BEGIN IMMEDIATE + busy 重试）。已落地
异步门面TaskRuntime 的 19 个 xxx_async 方法（写 16 + 读 3），内部统一 asyncio.to_thread 走同步实现，事务语义不变；事件循环调用方一律走 async 门面，线程/CLI 调用方继续用同步 API（ADR-0046）。已落地
TaskManager 适配core/interfaces.py 的 TaskManager ABC 提供非抽象默认 async 实现（to_thread 包装同步方法）；InMemoryTaskManager 内存直转；LegacyTaskManagerAdapter 转发 async 门面并套旧状态词表。已落地
