ADR-0040 · UI Feature 运行时能力状态源

2026-09-14 · 阶段 6AB · 状态：已实施（capability 套件 12 passed，后端全量与双端 typecheck/test 通过；三平台打包态验证待远程矩阵）。

背景与候选

Team/Kanban 的双端 reducer 已具备 init/dispose，但仍随整个 App 安装，缺乏可靠的功能启停状态来源。会话 mode 不能证明运行资源可用；新增布尔配置会复制 Runtime 状态；完整诊断响应包含 UI 不需要的配置修订、错误与 Lease 信息。

决定

由中立 Feature Runtime 提供按 Feature ID 索引的精简快照，经现有 config_body 的 feature_capabilities 字段返回。每项仅包含 state、available、generation；核心不枚举具体业务。product.team 与 product.dynamic-kanban 独立投影，缺席视为不可用。

可用性对应当前有效 Generation 的请求准入。drain 后新请求不可进入时立即不可用；replace 候选尚未发布而旧代仍可服务时保持旧代快照。读取不获取 Lease、不改变生命周期。该字段表示宿主运行时状态，不替代账号授权或后端请求门控。

边界、验收与回退

本片只交付后端状态源、双端可选响应类型和测试。Desktop/Web 动态安装、事件清理及页面投影在后续切片另行确认，不能凭本片宣称 UI 生命周期闭环完成。

测试覆盖缺席、激活失败、启停、drain、Generation 更新与 Team/Kanban 独立性，并验证现有配置响应和无 Runtime 测试替身兼容。纯 Python/JSON 契约不新增平台分支；三平台实测不得用单机结果替代。回退为撤销新增投影及可选类型，现有后端生命周期不变。
