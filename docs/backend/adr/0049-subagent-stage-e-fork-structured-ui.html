Ace / Backend ADR / 0049

Subagent 阶段 E：Fork、结构化输出与 UI Contribution

状态：已实施 · 日期：2026-09-17 · 适用分支：codex/subagent-multiagent-upgrade

背景

阶段 D 已提供持久子身份、隐藏会话和生命周期事件，但还缺少三类产品能力：从父会话已完成上下文创建隔离子会话、让子级返回可校验的数据对象，以及让 Web 消费子智能体运行状态。

决策

问题决策
Fork 语义新增 inprocess-fork Provider。它通过 SessionStore 读取 owner-scoped 父历史，只保留最后一个无工具调用 assistant 消息之前的已完成前缀；不使用 Unix 进程 fork，因此 macOS/Linux/Windows 语义一致。
历史净化Message 增加 source_kind，并与 is_meta 一起过滤提醒、技能上下文等内部消息；过滤依据是结构化字段，不扫描正文关键词。
结构化结果Provider 支持 output_schema 能力位。子作用域工具 structured_output 只对 schema-bound child 注入；ContextVar sink 做一次性提交与 JSON Schema 子集校验，成功后关闭 child iterator。兼容路径仍可从最终 JSON 文本解析。
Preset 权限增加 extends、subagents 和 read_only。继承在注册表 reload 时字段级合并并防循环；白名单同时收窄 schema 与 handler；只读 preset 结构性移除 shell/写类工具。
UI复用 FeatureEventRegistry，注册 run_started/run_settled，转为现有 status timeline；SubagentActivityView 轮询 api.subagents(sessionId)，归并活跃项、历史 runs 与生命周期消息，呈现紧凑只读活动卡。

能力边界

  • Fork 默认关闭，配置键为 subagent.fork_enabled；开启后 Provider 仍需显式选择。
  • Fork Provider 不支持 continuable，避免把一次性快照和持续身份混成两种生命周期。
  • 结构化输出当前以 JSON object 为提交形状，校验支持 object/array/string/number/integer/boolean/null、required、properties、items、enum 与基本长度/数值边界。
  • 旧的 delegate/run_agent 返回结构只增不改；structured 仅在存在时出现在结果中。

关键路径

delegate_task(output_schema)
  └─ StartRequest.output_schema
      └─ CrewApp child tool filter += structured_output
          └─ ContextVar sink → validate → single submit
              └─ Provider closes child iterator
                  └─ SubagentResult.structured

parent session → SessionStore.load(owner)
  → fork_completed_prefix(messages)
  → child SessionStore.save(owner)
  → existing Agent run loop

取舍与后续

本阶段选择值对象快照播种，保持实现简单且跨平台；后续如果父会话规模带来复制成本，可在 SessionStore 公共 fork API 上优化为事件链共享，但不改变 Provider 契约。UI 活动卡保持只读，数据由 owner-scoped API 投影与生命周期事件共同驱动，未知事件和无子智能体会安全降级为空。
