ADR-0013 · Background Result Notification Contributors

状态：Accepted · 日期：2026-09-03 · 阶段：插件架构 Stage 2 / Context Contributor 后续切片

背景

后台子任务、后台进程与任务恢复回合的结果通知，曾由三条中心特判路径注入模型上下文：CrewApp 持有 subagent 待注入队列并在 handle() 中手写 drain，runtime.py 用三个 _format_*_notifications 函数逐个检查 envelope.params 的魔法 key，team member 回合另有一条 subagent_drain_fn 构造参数旁路。新增一类后台结果必须同时改组合根、Agent Runtime 和 Team 接线。

决定

三条路径统一迁为 PROMPT 阶段 Context Contributor。队列所有权收归来源模块：subagent 待注入队列迁入 crew/agent/subagent/context.py，进程通知沿用 process_registry._pending，任务恢复回合只读 envelope.params["task_notifications"]。Agent Runtime 只运行通用 Prompt Contributor，不再包含通知格式化函数与魔法 key 检查。

职责所有者契约
subagent 完成队列与文案crew/agent/subagent/context.py按 (owner, session) 分键、单键限 20 条；drain 恰好一次；collect 按 task_id 摘除。
进程通知队列与文案crew/tools/process_registry.pyreader 线程入队不变；contributor 复用 format_process_notification 逐条格式化。
恢复回合任务通知crew/tasks/context.py只读 envelope params，不持队列；自动续跑行为不在本切片。
匹配与顺序Feature RuntimePrompt phase、priority 10/20/30，保持 reminder 块旧相对次序（通知在 cron/wiki 之前）。
team member 覆盖共享 Contributor 注册表member agent 持有同一注册表，drain 键落到 member 子会话；subagent_drain_fn 旁路删除。
撤销FeatureScopeContributor Token 随 Scope 精确释放，应用关闭统一等待。

行为兼容

  • 三个 reminder 块（# 后台子任务完成通知、# 后台进程通知、# 后台任务完成通知）输出文案与旧格式化函数逐字一致（AST 级对比验证）。
  • subagent 完成时的 WS status 直推保留在组合根，不经过通知贡献者。
  • preview_context 标记 _context_preview，预览不消费队列。
  • _resume_completed_task 的自动续跑行为不变，仅注入格式化改道。

边界与后续

本次只迁移模型可见的通知注入。用户可见的通知中心 publish（任务终态、审批、cron 完成）与 _resume_completed_task 的触发器化留作后续切片；Cron 的 Store/Scheduler 完整 Feature 化仍在阶段 3A。

跨平台

Contributor 只处理 Envelope 字段、队列与字符串，不引入进程信号、平台路径或线程语义变化。
