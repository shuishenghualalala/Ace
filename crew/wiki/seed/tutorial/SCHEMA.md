# SCHEMA — LLM Wiki 使用教程库

## Domain

LLM Wiki 产品使用教程：介绍 Crew 内置的 LLM Wiki 功能，包括理论背景（Karpathy 模式、与 RAG 的区别、人机分工）、界面功能（WikiHub、视图、图谱、开关）、对话交互（查/建/改/删）和端到端使用案例。

本库同时是功能演示：页面之间用 `[[链接]]` 互链，可直接在图谱视图中查看结构。

## 目录结构

```
tutorial/
├── SCHEMA.md      # 本文件
├── topics/        # 主题/话题页：总览、界面导览、对话指南、案例
└── concepts/      # 为便于维护分类存放；导入后仍是 topic 页面
```

## 标签体系

所有页面的 `tags` 只能从下表选取（可多选）：

| 标签 | 含义 |
|---|---|
| 入门 | 新用户最先读的总览性页面 |
| 理论 | 背景原理：Karpathy 模式、RAG 对比、人机分工 |
| 界面功能 | WikiHub 界面、视图、按钮、开关的说明 |
| 对话交互 | 如何用自然语言操作 Wiki |
| 案例 | 端到端使用故事：场景 + 步骤 + 结果 |

规则：新标签必须先加入本表，再用于页面。

## Frontmatter 约定

每个页面 = YAML frontmatter + Markdown 正文：

```yaml
---
page_type: topic             # 教程内容统一导入为受支持的 topic 页面
title: 页面标题               # 与文件名一致（不含 .md）
file_path: topics/页面标题.md # 与实际所在路径一致
sources: []                   # 教程库无外部来源，保持空数组
related: [其他页面标题]        # 关联页面标题，必须真实存在
tags: [标签体系中的标签]
aliases: [别名]
---
```

- 不要写 `id` / `created_at` / `updated_at`，由系统自动生成。
- 文件名中的冒号用全角「：」（半角冒号是非法文件名字符）。

## 正文规范

- 全中文，口语化但专业；每页 30–80 行，30 秒可读。
- 每页至少 2 个出链，格式 `[[其他页面标题]]`，目标标题必须存在。
- 功能说明具体到按钮/开关名字（如联网搜索复选框、上传按钮）。
- 不写「最新」「目前」等时效性词语。

## 页面阈值（简版）

- **建页**：教程覆盖的一个独立功能点、理论概念或案例 = 一页。
- **不建页**：一句话能说清的细节，并入所属功能页。
- **拆页**：页面超过约 80 行时拆分子页，互相链接。
