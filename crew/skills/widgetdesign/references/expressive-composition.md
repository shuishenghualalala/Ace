# Expressive Composition

This reference owns expression intensity, the dominant visual moment, and Pixel-role selection.
`brand-texture-language.md` owns field construction, archetype placement, and tier area guidance.

## Expression levels

Choose from task semantics before styling:

| Level | Use when | Pixel decision | Reject when |
|---|---|---|---|
| `utility` | repeated work, dense controls, lookup, monitoring, or operational build/readiness/health/status measures | use Hybrid Pixel Routing in `brand-texture-language.md` | treatment slows scanning or competes with controls |
| `expressive` | the user job genuinely requires a strong experiential, contextual, or conceptual treatment | use Hybrid Pixel Routing in `brand-texture-language.md` | memorability is the only rationale or treatment obscures the job |
| `resolve` | completion, milestone, success, launch, or an important final conclusion | use Hybrid Pixel Routing in `brand-texture-language.md` | ordinary progress, error, or routine output is made ceremonial |

Operational build, readiness, health, and status measures default to `utility` unless the user job
genuinely requires a stronger experiential treatment. Abstract versus representational geometry does
not select expression; an abstract field may support `utility`, `expressive`, or `resolve`. Use
`resolve` only when result semantics pass its gate.
Expression never overrides fit, accessibility, hierarchy, or task clarity.

## Dominant visual moment

Every widget has **exactly one dominant visual moment**: the P0 answer, value, state, choice,
relationship, or visual proof directly carrying P0. Before markup, complete: `The eye lands on ___
because it answers ___`.

If two regions compete in size, contrast, saturated color, motion, or texture, demote one. Headers,
controls, logos, grids, and Pixel fields cannot become co-dominant. Large type is earned by answer
importance and available space, not by brand theater.

## Default carrier selection

When the user provides no art direction, generate three internal candidates from the job before
choosing one: a subject/object carrier, a semantic information carrier, and a deliberately reduced
carrier. Select the candidate that makes P0 fastest to recognize and gives Regular a complete
composition without depending on decoration. Do not expose this comparison to the user.

Every selected semantic carrier must be subject-, data-, state-, or interaction-derived. A
brand-atmosphere carrier instead needs a named visual job such as build orientation, curiosity,
transition, or negative-space balance. Pure reduction is not visual omission: it needs authored scale,
proportion, alignment, contrast, and closed negative space.
Reject text on an empty surface, an interchangeable centered metric, or a generic card that could keep
the same composition after its title and value are swapped for an unrelated task.

Object anatomy, data marks, controls, routes, timelines, maps, and state geometry are visual carriers
before any house effect is added. Grid, Pixel, ASCII, Glass, contextual imagery, and motion may
strengthen the chosen carrier. Default Kimi's separate carrier gate determines when a Pixel/ASCII
field is required; Object-led mode remains free to omit it.

## Local Pixel Carrier

A Local Pixel Carrier is one coherent system, not wallpaper. `brand-texture-language.md` owns its
roles, coordinated-region rule, scale, label safety, Hybrid Pixel Routing, and tier options. This
reference only selects expression intensity and protects the dominant visual moment across Compact,
Regular, and Expanded.

## Failure and repair

Before using this table, complete semantic and placement repair in `adaptive-semantic-fit.md`, then
apply motif repair from `brand-texture-language.md`.

Classify the failure, then apply the first matching repair:

| Failure | Repair |
|---|---|
| Flat hierarchy | promote P0 through position, type role, or whitespace |
| Multiple focal points | retain P0; reduce competing scale, saturation, motion, and texture |
| Unclassified field | name its role and job; remove it when neither role can be justified |
| Field covers content | move it outside label-safe zones to an archetype-routed region |
| Same pattern everywhere | derive geometry and placement from local content and archetype |
| Compact feels crowded | after tier and placement fit pass, remove the selected Pixel option and then the nonsemantic grid fragment before reducing P0 type or labels |
| `resolve` feels theatrical | downgrade unless completion or milestone semantics are explicit |
| Blue or texture dominates | restore neutral hierarchy and token-driven supporting contrast |

After repair, restate the dominant-moment sentence and rerun all six carrier rules.
