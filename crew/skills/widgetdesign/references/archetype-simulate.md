# Simulate Archetype

Use when changing inputs should reveal consequences.

- **Dominant structure:** controls and one live output in the same visual field.
- **P0:** current output plus a concise input-state summary.
- **P1:** essential controls, ranges/units, assumptions required to use the result, and reset/default.
- **P2:** additional controls, scenarios, sensitivity, and evidence.
- **Compact:** output only; do not keep controls by relabeling them P0. **Regular:** essential controls
  beside output. **Expanded:** scenarios and assumptions.
- Every control must visibly affect the output. Separate assumptions from results and never place
  settings remotely from the value they change.
