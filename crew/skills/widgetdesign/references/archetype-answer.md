# Answer Archetype

Use when the user needs one conclusion, result, or recommended next fact.

- **Dominant structure:** conclusion/value first, followed by one structural proof rather than a
  paragraph or metric collage.
- **P0:** conclusion or result with direct label/state.
- **P1:** one reason, threshold, or next action needed to understand or use P0.
- **P2:** evidence, caveat, confidence, and supporting facts.
- **Compact:** P0 only. **Regular:** conclusion plus essential reason/action. **Expanded:** evidence
  and caveat without changing the answer.
- Use an action only when it completes the answer's job. Do not turn supporting facts into equal
  cards, and do not use a chart when one value or state is clearer.
