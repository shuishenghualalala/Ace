# Sequence Archetype

Use when the user needs order, progress, current stage, or the next transition.

- **Dominant structure:** directional rail, axis, lanes, or state machine with consistent connectors.
- **P0:** current stage/state and next transition.
- **P1:** completed/current/next sequence and blocker/action needed to continue.
- **P2:** full stages, timing, dependencies, exceptions, and recovery paths.
- **Compact:** current plus next state. **Regular:** essential rail. **Expanded:** complete inspectable
  sequence.
- Do not render unrelated cards as a timeline. Use labels and position before state color and keep
  connector direction unambiguous.
