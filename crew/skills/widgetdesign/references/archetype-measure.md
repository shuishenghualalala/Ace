# Measure Archetype

Use when the user needs magnitude, trend, distribution, progress, or a threshold.

- **Dominant structure:** value-axis field, metric plot, or minimal data instrument.
- **P0:** value plus unit and semantic state.
- **P1:** threshold/baseline and the shortest trend needed for interpretation.
- **P2:** axes, history, distribution, secondary series, source, and caveat.
- **Compact:** value/unit/state. **Regular:** threshold and short trend. **Expanded:** inspectable
  evidence with every label readable.
- A chart earns space only when it communicates more than the headline value. Read
  `data-visualization.md` for mark, scale, direct-label, legend, and collision rules.
