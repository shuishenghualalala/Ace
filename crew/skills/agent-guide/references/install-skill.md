# 使用手册 · 技能安装

本篇用于回答"如何安装/卸载技能""技能放在哪个路径""可安装技能怎么用"等问题。
当用户问这类问题时，依据本篇内容如实回答，不要凭空编造路径或命令。

## 技能是什么

技能（Skill）是封装好的一套能力。激活某个技能后，助手会按该技能的指令工作。
每个技能是一个**文件夹**，文件夹里至少有一个 `SKILL.md`，描述这个技能做什么、怎么用。

## 技能的 3 个来源

本平台中可用的技能来自三个来源：

1. **内置技能**：随平台自带，开箱即用，不需要安装。
2. **项目随附的可安装技能**：在“技能与插件 → 可安装”中浏览并安装。
3. **手动安装**：用户自己拿到技能包（压缩包或文件夹），按下方步骤放到指定路径。

> 安装后的技能和手动添加的技能最终都位于 `CREW_HOME/skills/`；默认 `CREW_HOME` 为 `.Crew/`。
> 内置技能不需要、也不能用这种方式安装。

## 安装项目随附的技能

1. 打开“技能与插件”页面并切换到“可安装”
2. 浏览或搜索项目随附的技能
3. 点击"安装"
4. 安装完成后，该技能出现在可用技能列表中，用 `/技能名` 激活即可

## 手动安装（压缩包或文件夹）

当你拿到一个技能压缩包或文件夹时，按以下步骤安装：

1. **解压**压缩包（`.zip` 等格式），得到一个技能文件夹。
2. **确认结构**：这个文件夹里要**直接包含** `SKILL.md`。正确结构是：
   ```
   某个技能文件夹/
   └── SKILL.md
   ```
   如果解压后多套了一层目录，请往里找到直接包含 `SKILL.md` 的那一层，把它作为技能文件夹。
3. **放到指定路径**：把这个技能文件夹放到 `CREW_HOME/skills/` 目录下。最终结构应为：
   ```
   CREW_HOME/skills/
   └── 某个技能文件夹/
       └── SKILL.md
   ```
4. **刷新**：回到平台刷新技能列表（或重新进入会话），该技能即出现在可用列表中。
5. **激活**：用 `/技能名` 激活使用。

### 注意事项

- 技能文件夹名建议用小写字母和连字符（如 `my-skill`），避免空格和中文。
- 如果新装的技能与某个内置技能同名，新装的会覆盖内置的。
- 如果技能文件夹里没有 `SKILL.md`，这个技能不会被识别。
- 技能文件夹里可能还带 `scripts/`（脚本）、`references/`（参考文档）等附属文件，
  `SKILL.md` 会引用它们。**保留整个文件夹原样**，不要只拷贝 `SKILL.md`。

## 卸载技能

- **安装的或手动添加的技能**：可以在“已安装”中点击卸载，也可以删除 `CREW_HOME/skills/` 下对应的技能文件夹。
- **内置技能**：随平台自带，无法单独卸载。

## 常见问题

**装完技能但列表里看不到？**
- 检查 `CREW_HOME/skills/<技能文件夹>/` 下是否**直接**存在 `SKILL.md`。
- 检查是否多套了一层目录（`SKILL.md` 必须就在技能文件夹这一层，不能再嵌套）。
- 刷新技能列表，或重新进入会话再查看。

**技能文件夹里除了 `SKILL.md` 还有别的文件，正常吗？**
- 正常。技能可以带 `scripts/`、`references/` 等附属文件，保留整个文件夹原样即可。

**手动添加和界面安装有冲突吗？**
- 没有冲突。两者都使用 `CREW_HOME/skills/`，只要技能文件夹名不同就各自独立存在。
